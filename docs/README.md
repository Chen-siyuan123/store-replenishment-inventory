# 文档索引

按项目推进顺序分为三段。评审或答辩时建议按 `requirements → design → delivery` 的顺序阅读。

## requirements/ 需求与调研

回答「为什么做、给谁做、做什么」。

| 文档 | 内容 |
|---|---|
| `社区连锁超市补货与库存协同-行业分析报告.docx` | 行业背景、8 家试点门店的业务现状、补货环节的痛点归因 |
| `门店补货与库存协同-一页纸需求清单.html` | 需求范围收敛：做什么、不做什么、优先级与验收口径 |
